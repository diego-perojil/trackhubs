Conserved Non-coding Elements (CNEs) — short non-coding sequences under strong purifying selection — discovered by whole-genome pairwise alignment between this reference genome and each query species, then scanned with CNEr.

Track types

  • CNEs (perfect) — CNEs at 100% identity, by minimum length window.
  • CNEs (partial) — CNEs at <100% identity, by identity × window.
  • CNE density — CNE density (bigWig), coloured per threshold (inferno ramp).
  • Collinearity — CNE order conservation: rank2, interaction arcs, per-bp and single-link collinearity.

Each composite is a species × threshold matrix: pick species and stringency from the matrix to reveal tracks (all start hidden so the hub opens light). Feature tracks carry maxWindowToDraw, so zoom in to draw them; the density bigWigs give the wide-zoom overview.
